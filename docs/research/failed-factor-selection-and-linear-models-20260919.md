# 日频因子筛选与线性模型未晋级实验记录（2026-09-19）

本页记录已经完成、但不再保留大型训练产物的探索实验。统一口径为 raw OHLCV
因子值、QFQ 开盘到开盘标签、CSI300∪CSI500 滚动训练、CSI500 Top100、退出
Top120、每日最多主动替换 3 只、买入 2.1bp/卖出 7.1bp。结论只适用于当前
2018--2026 数据快照和执行器。

## 未晋级方案

| 方案 | 主要结果 | 结论 |
|---|---|---|
| 近期季度稳定性 Top20 + LGBM | H1 IC 1.73%，H5 1.32%，H10 2.09%；H1/H5 回测净收益 23.27%，复合超额 -7.02% | 使用未来季度信息，且样本外表现差；删除缓存、模型和回测。 |
| 2021Q2 前稳定性 119 因子 + LGBM | H1 IC 2.37%，H5 1.12%，H10 1.24%；H1/H5 回测净收益 18.44%，复合超额 -12.54% | 无未来泄漏但筛选规则不适合 LGBM；相关产物此前已删除。 |
| 稳定性筛选后相关性去重 70 因子 | 仅生成不完整研究缓存，未形成可晋级模型 | 路线被 119 因子对照取代；删除不完整缓存和筛选目录。 |
| 全 272 因子 Ridge | 全期 H1/H5/H10 Rank-IC 2.50%/1.74%/2.24%；净收益 35.52%，IR 0.082，最大回撤 -33.18% | 2025--2026 IC 较强，但未转化为全期组合收益；不晋级。 |
| 全 272 因子 Elastic Net | 全期 H1/H5/H10 Rank-IC 2.25%/1.81%/2.15%；净收益 50.78%，IR 0.330，最大回撤 -32.73% | 能动态稀疏，但 H1 有两个季度为空模型、共 242 个交易日无有效排序；不作为独立模型晋级。 |

线性模型采用 Rust 按滚动窗口从长表读取、逐日截面标准化并写临时列主序
float32 memmap，Python 只累计 Gram 矩阵并求解；22 个季度全部完成且 Elastic Net
均收敛。该实现验证了无需永久落盘 272 列历史宽表，但模型结果没有超过 Top60-LGBM。

## 保留的候选

按原 Daily60 规则在已有 CSI500 日频因子评估上重筛：截至 2024-12-31，最近
504 个交易日、126 日半衰期，取 H1/H5 最大绝对年化 Rank-ICIR 前 60，不使用季度
相关性或因子相关性去重。新旧 raw Daily60 重合 43 个、替换 17 个。

新 Top60-LGBM 的 CSI500 H1/H5 回测净收益 72.22%，IR 0.474，最大回撤 -27.74%；
H1-only 净收益 71.60%。旧 raw Daily60 的对应 H1/H5 与 H1-only 分别为 60.86%
和 65.84%。因此只保留新 Top60 名单、特征缓存、模型预测与回测，并继续测试其与
已生产 Minute45 的组合。
