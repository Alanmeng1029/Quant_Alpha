# Optimizer v2：真实持仓驱动的有限换仓

> 历史基线：本文记录 98 因子阶段对 Optimizer V2 的建立与敏感性分析。策略机制仍在使用，但当前正式版本已升级为 105 因子、历史中证500内 Top100/每日最多换3只；最新含费回测见 [`../PRODUCTION_BACKTEST.md`](../PRODUCTION_BACKTEST.md)。早期 98 因子结果还受到执行日历映射问题影响，修正后的同口径 Top80/换仓5累计净收益为 74.32%。

日期：2026-09-06。此版本替代了将“昨日目标权重”当作真实仓位、每日重新配平的研究型 optimizer。它不重新训练模型，直接读取 Daily60 + Minute38 的既有 OOS `pred_h1`、`pred_h5`。

## 账户与时点

1. T 日收盘后，在 CSI300 ∪ CSI500 的信号截面分别标准化 `pred_h1`、`pred_h5`，各占 50%，同分按股票代码排序。
2. T+1 开盘先卖后买。账本保存现金、复权等价股数、上一次可用估值；下一日决策读取成交后的真实状态，而不是昨日目标权重。
3. 每日以当前开盘估值，并持有至下一交易日开盘。缺报价或不可交易订单不会虚构成交，也不会预先释放现金或名额。
4. 买入费率为 2.1bp，卖出费率为 7.1bp，按 100 股整手向下取整。复权等价股数仅服务研究收益口径，不表示企业行动登记股数。

## 默认组合规则

| 规则 | 值 |
| --- | ---: |
| 目标持股数 | 80 |
| 候选进入排名 | 前 80 |
| 正常退出排名 | 跌出前 96 |
| 每日主动新增上限 | 5 只 |
| 单票上限 / 风险降至 | 3.0% / 2.8% |
| 新仓最小规模 | 调仓前净资产的 0.5% |
| 现金预留 | 2% |
| 买入、卖出日预算 | 各为调仓前净资产的 10% |

首日一次性建仓前 80 名。之后持有股票保持股数，不为恢复等权而交易。成分退出与单票上限处理优先于普通排名替换；成分退出造成的空缺优先占用当日新增名额，防止在持续替换时永久积累现金。风险处置若超出日常成交预算会在订单账本中标为 `budget_exception`。

## 产物与复现

主版本位于 `results/predict/open-open-daily60-minute38-lgbm-v1/limited-replacement-v2-80x5/`：

- `manifest.json`：输入预测指纹、策略参数与成本假设。
- `orders.parquet`、`executions.parquet`：订单原因、未成交状态、费用与预算例外。
- `holdings.parquet`、`portfolio_daily.parquet`、`annual_metrics.parquet`：实际持仓、现金和按年表现。
- `zero_cost/`：从初始资金独立运行的零费率账本。

```bash
PYTHONPATH=src python -m a_share_data.predict backtest-policy \
  --catalog A_stock_database/lake/catalog/a_share.duckdb \
  --predictions results/predict/open-open-daily60-minute38-lgbm-v1/predictions.parquet \
  --output results/predict/open-open-daily60-minute38-lgbm-v1/limited-replacement-v2-80x5
```

这仍是日频、开盘成交的研究模拟：没有盘口冲击、涨跌停成交概率、容量或借券约束。参数敏感性用于理解换手—信号权衡，不应用全历史结果自动挑选版本。

## V3：排名倾斜的新仓规模

V3 保留 V2 的账户闭环、80 只上限、有限替换、现金预算和“不为恢复等权而交易”的规则。唯一变化是新仓初始金额：前 80 名按线性排名得到均值为一的乘数，第一名为 `1 + rank_tilt`、第 80 名为 `1 - rank_tilt`；默认 `rank_tilt=0.15`，即约为 NAV 的 1.04% 至 1.41%。

它只在开新仓时使用预测强度；旧仓不因分数改变而被重新配平。因此 V3 是温和的组合构造扩展，而非将每日标准化预测直接当作收益预测做全量交易。

在同一 2021-04 至 2026-08 区间，V3（0.15 倾斜、最多替换 5 只）净收益为 68.32%、IR 为 0.464、单边日均换手为 3.95%、平均持股为 77.98。它低于 V2 的 73.27% 与 0.532，故 V3 保留为独立对照，而 V2 继续是正式策略版本。
