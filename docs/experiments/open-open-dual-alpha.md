# 双周期 LightGBM 与换手约束组合：OOS 回测

日期：2026-09-02。此文档记录当前保留的预测与组合产物，替代早期 VWAP、Top10 和 OSQP 测试实验。

## 协议

- 股票池：每日 CSI300 ∪ CSI500 的可交易股票；`000937.SZ` 因供应商复权因子异常而剔除。
- 特征：33 个 `|ICIR| > 3` 候选日频因子；每日 1%/99% 去极值与截面 Z-score。
- 标签：信号 T 收盘后，T+1 开盘进入；h1 为 T+1 开盘至 T+2 开盘，h5 为 T+1 开盘至 T+6 开盘；均减同期 CSI500 开盘到开盘收益。
- OOS：每月滚动训练，训练窗 756 个交易日，6 日标签空档；2021-04-01 至 2026-08-28。
- 模型：两个独立 LightGBM 回归器，输出 `pred_h1` 和 `pred_h5`。
- 组合：每个截面标准化 h1/h5 预测，50/50 合成并用 temperature=2.0 的 softmax 转为长仓；单票最大 10%，单边换手上限 30%。不设 Top-N、行业或中证500权重约束。
- 回测：T+1 开盘到下一执行日开盘；按相邻仓位差额成交，买入 2.1bp、卖出 7.1bp；收益与 CSI500 开盘到开盘比较。

## 限制

该组合覆盖几乎整个可交易池，是受换手约束的广泛分散 alpha 倾斜，并非“前50只”或集中的选股策略。结果大幅优于每日 Top10 的主要原因是换手从约 69% 降到约 17%，而非 optimizer 凭空生成 alpha。

复权序列只剔除了已确认异常的 `000937.SZ`；尚未完成系统性的企业行动与供应商复权审计。没有模拟停牌、涨跌停、冲击成本、容量或一手整数执行，因此该产物只用于研究，不能直接实盘。
