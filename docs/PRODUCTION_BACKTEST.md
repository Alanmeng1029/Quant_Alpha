# 当前生产版本回测

快照日期：2026-09-20。

当前正式基线是125因子 `o2o_raw_daily60_minute45_dos20_v1`、默认 LightGBM 回归模型的 H1 预测，以及不含风险项的成本感知 optimizer。策略仅在信号日历史 CSI500 成分内优化；目标函数为：

```text
maximize mu'w - 2bp * buys - 2bp * sells
```

约束为98%投资、单票上限1%，因此目标组合通常为98只股票、每只1%。版本化配置见 [`production_strategy_csi500_h1_mu_turnover_2bps_v3.json`](../configs/production_strategy_csi500_h1_mu_turnover_2bps_v3.json)。旧105因子 Top100/Exit120/每日最多替换3只的配置已标记为 `superseded`。

## 固定口径

- 因子集：60个 raw 日频 + 45个既有分钟 + 20个新 DOS 分钟因子，共125个。
- 模型：默认 LightGBM 回归；CSI300 ∪ CSI500 训练；756交易日窗口、11日标签隔离、季度滚动重训。
- 信号：只使用 H1；标签为个股 T+1 开盘至 T+2 开盘收益减同期 CSI500 收益。
- 交易池：信号日历史 CSI500 成分，来自 `index_trading_universe`。
- optimizer：无协方差或其他风险项；只优化预测收益减买卖换手成本。
- 组合：98%投资、单票上限1%；不存在“每日最多换几只”的硬限制。
- 执行：T日收盘后产生信号，T+1开盘按100股整手交易，真实现金和持仓滚动。
- 成本：买入2bp、卖出2bp。
- 基准：CSI500价格指数，不是全收益指数。

## 生产风险

- 平均单边换手约39%，远高于旧 Swap3 基线；2bp是研究假设，不包含完整冲击成本与容量退化。
- optimizer 没有风险模型、行业约束或风格约束，可能形成不可见的集中风险。
- 2021-04 至 2026-08 已参与多轮模型与执行方式比较，存在选择偏差。
- 当前缺少完整历史 ST、停复牌、涨跌停成交概率、全收益指数和盘口级成交模拟。
- 正式监控必须同时记录预测尺度、实际换手、成交偏离和费用；不能只监控净值。

这些结果只说明当前历史样本和数据口径下的表现，不构成收益承诺。
